---
name: file-organizer
description: Organize or rename a collection of files using explicit rules while handling collisions and preserving originals.
metadata:
  category: productivity
---

Inventory the requested directory and derive a source-to-destination map before modifying files. Limit operations to the requested scope. Detect duplicate destinations, existing-file collisions, case-only renames and files that changed after inspection. Use temporary names for rename cycles. Do not silently overwrite or delete content to resolve collisions. Carry out authorized moves through available execution tools; inspection alone is not completion. Keep a manifest of completed operations, inspect actual destinations after partial failure, and resume only remaining moves rather than replaying the full batch. Verify destination existence and content hashes where practical.
