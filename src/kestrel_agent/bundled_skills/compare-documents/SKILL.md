---
name: compare-documents
description: Compare documents, contracts, reports, or versions while preserving meaning and tracing differences to their sources.
metadata:
  category: documents
---

Read each named document completely enough to cover the requested comparison. Check pagination, extraction limitations, tables and missing sections; retrieve omitted ranges before concluding. Align equivalent sections by meaning, not only heading text. Separate additions, removals, numeric changes and changes in obligations. Quote only short identifying fragments; cite source names and page/section locations where present. Do not infer that absent extracted text proves content is absent in a scanned document. For requested edits, preserve unrelated material and verify the saved artifact. Return only the comparison scope and output format requested.
